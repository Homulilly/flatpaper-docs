# 留言板 (Guestbook)

FlatPaper 提供了极具个性化的留言板功能，支持将传统的博客评论渲染为一面「留言墙」（彩色便签贴纸形式），让读者留言更具趣味性和互动性。

## 快速创建

使用 Hexo 命令在站点根目录创建留言板页面：

```bash
hexo new page guestbook
```

然后修改生成的 `source/guestbook/index.md` 文件，设置其 `type` 为 `guestbook`：

```yaml
---
title: 留言板
type: guestbook
page_size: 12
---

这里可以写一段话作为留言板的开场白（支持 Markdown），它会渲染在留言墙的上方。
```

## 属性配置

在留言板页面的 Front-matter 中，支持配置以下属性：

| 属性 | 类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `type` | String | 必填 | 必须设置为 `guestbook` 以启用留言墙布局。 |
| `page_size` | Number | `12` | 控制每批展示的便签张数（默认 12，最高 50），超出部分将通过「展开更多留言」按钮加载。 |

## 前置条件

使用留言板功能前，你必须在主题配置文件 `_config.yml` 中启用并配置以下评论系统之一：
- **Twikoo** (`comments: twikoo` 并配置 `twikoo.envId`)
- **Artalk** (`comments: artalk` 并配置 `artalk.server`)

*若未配置评论系统，墙面将显示相应的配置提示。*

## 行为与特性

- **个性化视觉效果**：每条留言的便签纸色、上方固定的胶带颜色以及歪斜角度均基于留言 ID 确定性生成，排版错落有致。
- **多种排序模式**：默认采用随机排序（错落有致的便签布局），并提供切换按钮可切换至“最新优先排序”（整齐的网格布局，方便按时间阅读）。
- **智能内容提取**：便签会展示留言纯文本，并能从 Twikoo HTML 或 Artalk Markdown/HTML 中智能提取图片与表情缩略图；不安全的图片链接会被过滤。
- **展示规则**：
  - 墙面只展示主楼留言（最新 100 条以内），楼中楼的回复需在页面底部的常规评论区查看。
  - 每张便签贴纸上均有「查看留言」链接，点击即可平滑跳转到下方常规评论区的对应位置。
  - Twikoo 留言会正常展示头像；因 Artalk 公开接口不返回头像地址，Artalk 模式下便签会统一使用昵称首字符作为替代头像。
